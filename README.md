# Clipboard Vault · 剪切板归档

Windows 桌面版 Obsidian 插件。Obsidian 运行期间检查剪切板，将新复制的文本、网址、代码、截图和文件路径存入 Vault。Android 端通过既有的 Vault 同步方式查看结果。

## 安装

1. 在 [GitHub Releases](https://github.com/GraniteNo/obsidian-clipboard-vault/releases/latest) 下载 `clipboard-vault-1.4.2-install.zip`。
2. 解压安装包，将整个 `clipboard-vault` 文件夹放入你的 Vault 的 `.obsidian/plugins/` 下。升级时覆盖旧文件；请保留新的 `clipboard-helper.ps1`。
3. 重启 Obsidian，在“设置 → 第三方插件”中启用 **Clipboard Vault**。
4. 点击左侧剪切板图标打开管理面板；在“设置 → Clipboard Vault”调整保存根目录、日期文件夹层级、监控间隔及过滤规则。

插件需要 Obsidian **1.5.0 或更高版本**，支持 Windows 桌面端。当前通过 GitHub 安装包手动安装。

每天一个汇总笔记，记录按 `1.`, `2.` 等序号排列。默认保存为 `剪切板/YYYY/MM/DD/YYYY-MM-DD.md`；可以改为 `剪切板/YYYY/MM/YYYY-MM-DD.md`、仅按年分目录，或直接放在根目录。图片在对应笔记所在目录的 `attachments/` 下。调整层级后，已有文件不会自动搬迁。同步这些文件后即可在 Android 查看。插件不会主动上传数据，也不会在 Obsidian 关闭后继续监控。

## 操作

- 左侧图标打开面板，可暂停、恢复、立即捕获、打开今日归档。重复点击会回到已有面板，不会再创建多个页签。
- 「浏览归档」默认只显示今天的记录，可切换到昨天、最近 7 天、指定日期或全部日期。跨日记录按日期分别分组，点击日期标题可折叠或展开；每组条数是本页显示的数量。支持叠加类型和关键词筛选。图片记录显示缩略图；混合记录可分别复制图片和文件路径。浏览和搜索直接读取已有归档，不需要迁移旧笔记。
- 点「定位原文」跳到每日笔记中的对应标题。文字、链接、代码和文件路径可以直接复制；「复制图片」将选中的图片作为位图放入 Windows 剪切板。面板发出的复制会被 Windows 自动监控跳过，仍可用「立即捕获」手动保存。
- 点击底部状态栏或面板的「暂停监控」，可选择暂停 5、15、30 分钟，或暂停到手动恢复。定时暂停在重启后继续计时；恢复时跳过剪切板上已有的内容。暂停期间仍可点击「立即捕获」。
- 「撤销最近捕获」会选中最近保存的一条记录，确认后移除。也可在任意记录卡片上点「删除条目」。移除后，当天笔记中的剩余条目会按原顺序从 1 开始连续编号，新捕获接着编号。重编只修改条目标题的序号，不改正文、时间和附件。图片附件默认保留，勾选后才把此次归档创建且没有被其他笔记引用的附件移到回收站。
- 命令面板可切换监控、立即捕获和撤销最近捕获，可自行绑定快捷键。
- 自动监控启动时把当前剪切板作为基线，不会自动存入启动前已复制的内容。要保存它，请点击“立即捕获”。
- 相同内容默认当天只保存一次。此状态记录在当天的 Markdown 中，重启后仍有效。
- 复制截图或图像数据时保存 PNG 附件。复制资源管理器里的图片文件时，可在设置中的“复制图片文件时”选择“保存为附件”或“只记录文件路径”；默认保存为附件。附件模式保留图片原格式，可一次导入多张图片。其他文件和文件夹仍只记录路径。
- 可导入 PNG、JPG、JPEG、GIF、WebP、BMP、AVIF、SVG 图片。单张图片超过 50 MB、一次复制的图片总量超过 200 MB，或源文件读取失败时，插件改为记录原路径并显示提示。已归档的旧记录不会因切换选项而自动改变。
- 疑似密码或密钥及自定义关键词可跳过。过滤只适用于文本和路径；图片可能包含敏感内容，请按需暂停监控。

## 兼容性

在 Windows 上，插件优先运行随包提供的本地 PowerShell 剪切板读取程序，以识别图像数据和资源管理器的文件列表。它不会向网络发送数据。如果该程序无法运行，插件继续尝试 Electron 和浏览器剪切板接口；备用接口可能要求 Obsidian 在前台或取得剪切板权限。若状态栏显示“原生读取不可用”或“读取失败”，请在 Obsidian 前台尝试“立即捕获”，并检查 `clipboard-helper.ps1` 是否在插件目录中。持续后台监控需在你的 Obsidian 版本上实际验证。

## 从源码构建

需要 Node.js 22 或更高版本。在项目目录依次运行：

```sh
npm ci
npm run check
npm run build
npm test
```

将生成的 `main.js`、`manifest.json`、`styles.css` 和 `clipboard-helper.ps1` 放在 `.obsidian/plugins/clipboard-vault/` 中。
